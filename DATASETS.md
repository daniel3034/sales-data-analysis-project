# Recommended Datasets for Sales Analysis

## Option 1: Superstore Sales Dataset ⭐ RECOMMENDED

**Link:** https://www.kaggle.com/datasets/vivek468/superstore-dataset-final
**Size:** ~10,000 rows
**Why it's good:**

- Clean and well-documented
- Has categories, dates, sales, profit columns
- Perfect for answering both questions
- Commonly used for learning

**Columns include:**

- Order Date (for monthly trends)
- Category, Sub-Category (for grouping)
- Sales, Profit (for revenue analysis)
- Region, State, City (additional analysis options)

## Option 2: Online Retail Dataset

**Link:** https://www.kaggle.com/datasets/vijayuv/onlineretail
**Size:** ~500,000 rows
**Why it's good:**

- Real e-commerce data
- International dataset (UK-based)
- Good for time series analysis

**Columns include:**

- InvoiceDate
- Description (product)
- Quantity
- UnitPrice
- CustomerID
- Country

## Option 3: Sales Product Data

**Link:** https://www.kaggle.com/datasets/knightbearr/sales-product-data
**Size:** ~200,000 rows
**Why it's good:**

- Multiple products
- Monthly data ready
- Clear pricing information

## How to Download:

1. **Create a Kaggle account** (free)

   - Go to https://www.kaggle.com
   - Sign up with Google or email

2. **Download the dataset**

   - Click the dataset link
   - Click "Download" button
   - Extract the ZIP file if needed

3. **Place in your project folder**
   - Copy the CSV file
   - Paste into your project root folder
   - Rename to `sales_data.csv` (or update the filename in the code)

## What to Look for in a Dataset:

✅ Has a date/time column
✅ Has categorical columns (product types, categories)
✅ Has numerical columns (sales, revenue, quantity)
✅ At least 1000+ rows
✅ Good documentation
✅ CSV format
✅ No complex encoding issues

## After Downloading:

1. Open the CSV in Excel or a text editor to preview
2. Note the column names
3. Check the date format
4. Verify you have sales/revenue data
5. Identify the category column
